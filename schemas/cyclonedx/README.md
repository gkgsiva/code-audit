# CycloneDX schemas (vendored)

`bom-1.5.schema.json`, `spdx.schema.json` and `jsf-0.82.schema.json` are copied unchanged from
<https://github.com/CycloneDX/specification> (tag `1.5`, folder `schema/`), published under the
Apache License 2.0. `tests/security/test_sbom.py` validates the generated `sbom.cdx.json`
against them offline.
